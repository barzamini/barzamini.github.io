# Hamed Barzamini - Academic Website

This is the source code for my academic website hosted on GitHub Pages at [barzamini.github.io](https://barzamini.github.io).

## About

This website uses a custom single-page HTML template with embedded CSS and JavaScript. It's based on Ali Cheraghian's website template and customized with my personal information, publications, and research highlights.

## Structure

- `index.html` - Main single-page website
- `images/` - Profile photo and other images
- `assets/pdf/` - PDF files (CVs and publications)

## Deployment

The website is automatically deployed to GitHub Pages when changes are pushed to the `main` branch.

## Local Testing

Simply open `index.html` in a web browser to view the site locally.

## Customization

To update content:
- Edit `index.html` directly
- Update the header section for personal information
- Modify the news section for recent updates
- Update the publications section with new publications
- Replace `images/profile.jpg` with your profile photo
