## Research Interests

- **Requirements Engineering for AI Systems**: Developing systematic frameworks for specifying and evaluating domain requirements in ML-based software
- **AI-Enabled Perception Systems**: Black-box evaluation, dataset quality assessment, and model generalizability
- **Semantic Web Technologies**: Multi-level semantic representations for domain concept specification
- **Concept Drift Detection**: Adaptive mechanisms for detecting and handling domain shifts in AI systems
- **Safety-Critical Systems**: Evaluation frameworks for autonomous driving and ADAS applications

## Recent Highlights

- **B-AIS Framework**: Developed automated black-box evaluation system achieving **95% F2-score** for pedestrian detection
- **CADE Benchmark**: Created systematic dataset evaluation framework identifying **25% deficiencies** in dataset alignment
- **V-REX Framework**: LLM-driven requirements engineering framework reducing model bias by **7.3%** and improving accuracy by **4.9%**
- **ODD Specification**: AI-driven framework for operational design domain specification in autonomous driving, improving dataset alignment by **35%**
